# Ronron
**Dá swipe. Dá um lar.** Gatos de rua à procura de casa em Portugal.

Quem cuida de gatos de rua publica-os; quem quer adotar conhece-os um a um e fala diretamente com quem cuida deles. Adoção sempre gratuita.

- App Android: `app/` (Vite + Capacitor 8, pacote `pt.ronron.app`). Compilação em `.github/workflows/android.yml`.
- Base de dados: Supabase (`supabase/migrations`, testes em `supabase/tests`).
- Páginas públicas (GitHub Pages): [política de privacidade](https://giuseppelomb.github.io/Ronron/privacidade/) e [eliminação de conta](https://giuseppelomb.github.io/Ronron/apagar-conta/).
- Google Play: `docs/PLAY-CONSOLE.md`.
